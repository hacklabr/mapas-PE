# Decisões técnicas (ADRs)

> Criado em: 2026-08-21 · Última revisão: 2026-08-21

Registros de decisão com consequência duradoura. Numeração sequencial de 4 dígitos (a próxima é o máximo existente + 1); ADRs aceitos são imutáveis — nova decisão que substitui uma anterior cria um NOVO ADR referenciando o substituído (`substituído por ADR-NNNN`).

Status possíveis: `proposto` / `aceito` / `substituído por ADR-NNNN`.
